# 作品联动与中文片名

2026-10-28：用户批准推荐方案，并明确允许美区待播电影检索 TMDB 后严格核验。

## 范围

- 本地已有 19 部片库作品关联外部榜单，复用 video_id，不按标题重新匹配。国内待播使用已缓存 sourceRefs 的原站 ID，冲突不关联。
- 39 部 WTS 详情实测均无 IMDb 链接。提取详情原名、标题年份与导演；仅对此范围检索 TMDB，精确比较归一化原名、年份及导演集合，候选唯一才写独立本地中文／IMDb 身份缓存。没有中文标题仍保留英文，证据不足不匹配。
- 中文标题仅展示，原始标题、排期、地区、去重身份不变；补全缓存记录证据指纹，原始身份材料改变后作废。
- 外部榜单本地共享摘要，电影／剧集／待播与详情复用。榜单定位保留来源及席位身份。来源关闭隐藏相应联动。
- 静态柔光表示有榜单记录，鲜明琥珀边表示近期有效热度；口碑／评分／预约单独说明。仅 is_current 且采集和读取均不超过 48 小时才启用热度强调，这是界面新鲜度标准，不推断下榜。
- 动效只在悬停或已观察到的有效变化时播放一轮；遵循减少动态效果与窗口活跃状态，不增加常驻计时器。

## 🔴 致命弱点

WTS 缺少共享身份，直接拿搜索第一项会关联错作品。必须原名／年份／导演互证及唯一候选；没有证据保持未关联，绝不退化为模糊片名匹配。

## 🟡 主要缺陷

- 外部榜单保留截断旧记录：不能仅凭 is_current 点亮正在热门，必须检查采集时间，旧记录灰显。
- 首次获取无 previous_rank 不等于新入榜：不制造新入榜变化；上涨只在同席位有效前后名次能相互校验时展示。
- 多源名次不能比较：摘要保留各自来源和榜单，不计算综合热度。
- 长期多卡动画损害低内存／低空闲负载：使用有限时长的描边和位移动画，后台与减少动态效果关闭。

## 🟢 改进建议

先验证关联与新鲜度模型，再接 UI；对中文匹配覆盖重拍同名、导演不符、年份不符、多候选、无译名、旧缓存；对联动覆盖关闭来源、冲突身份及按作品分页。最终用真实应用验证详情跳转、中文／原名展示、光边与窄窗口。

## 📋 审查总结

采用独立身份补全缓存和本地信号展示，保留既有主库与排名语义。验证不足的影片继续保留原名和未关联状态。
