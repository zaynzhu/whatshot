# 作品联动与中文片名

2026-10-28：用户批准推荐方案，并明确允许美区待播电影检索 TMDB 后严格核验。

## 范围

- 本地已有 19 部片库作品关联外部榜单，复用 video_id，不按标题重新匹配。国内待播使用已缓存 sourceRefs 的原站 ID，冲突不关联。
- 39 部 WTS 详情实测均无 IMDb 链接。提取详情原名、标题年份与导演；仅对此范围检索 TMDB，精确比较归一化原名、年份及导演集合，候选唯一才写独立本地中文／IMDb 身份缓存。没有中文标题仍保留英文，证据不足不匹配。
- 中文标题仅展示，原始标题、排期、地区、去重身份不变；补全缓存记录证据指纹，原始身份材料改变后作废。
- 外部榜单本地共享摘要，电影／剧集／待播与详情复用。榜单定位保留来源及席位身份。来源关闭隐藏相应联动。
- 静态光边及海报内角标表示榜单记录：近期热度用琥珀，近期预约／口碑／评分等用青色，较早记录用灰色；角标明确区分含义。仅 is_current 且采集和读取均不超过 48 小时才启用热度强调，这是界面新鲜度标准，不推断下榜。
- 动效只在悬停或已观察到的有效变化时播放一轮；遵循减少动态效果与窗口活跃状态，不增加常驻计时器。

## 🔴 致命弱点

WTS 缺少共享身份，直接拿搜索第一项会关联错作品。必须原名／年份／导演互证及唯一候选；没有证据保持未关联，绝不退化为模糊片名匹配。

## 🟡 主要缺陷

- 外部榜单保留截断旧记录：不能仅凭 is_current 点亮正在热门，必须检查采集时间，旧记录灰显。
- 首次获取无 previous_rank 不等于新入榜：不制造新入榜变化；上涨只在同席位有效前后名次能相互校验时展示。
- 多源名次不能比较：摘要保留各自来源和榜单，不计算综合热度。
- 长期多卡动画损害低内存／低空闲负载：使用有限时长的描边和位移动画，后台与减少动态效果关闭。

## 🟢 改进建议

先验证关联与新鲜度模型，再接 UI；对中文匹配覆盖重拍同名、导演不符、年份不符、多候选、无译名、旧缓存；对联动覆盖关闭来源、冲突身份及按作品分页。最终用真实应用验证详情跳转、中文／原名展示、光边与窄窗口。

## 📋 审查总结

采用独立身份补全缓存和本地信号展示，保留既有主库与排名语义。验证不足的影片继续保留原名和未关联状态。

## 连接误报与视觉增强（2026-10-29）

- 实际错误为 `服务不可达 · cancelled`：停止主同步后，外部热度步骤把取消当成连接失败。健康检查与榜单接口实际均返回 HTTP 200。修复后取消保留原连接状态和快照，真实连接失败仍记录错误。
- 独立「刷新热度」复用原同步步骤，无需等待主站探活、首播日或海报补全；与主同步互斥，WhatsNew 客户端共享 ≥2 秒限频。支持停止，关闭外部来源或变更地址会取消该刷新。请求成功时间与各榜原始采集时间分别显示。
- 热榜描边由 1.5 加粗到 3 点，增加海报内分类角标及实色榜单按钮；预约／口碑等使用青边，旧记录灰显。保留单次扫光和减少动态效果支持。
- 回归测试先复现健康检查／详情请求取消造成的 6 项断言失败，修复后外部热度与关联相关的 39 项测试通过，生产构建及签名通过。
- 实机独立刷新成功，页面显示「覆盖 50 部作品 · 更新于刚刚」；再次刷新并停止后仍保持 `ok` 状态及旧快照，没有「服务不可达」误报。截图确认热榜金边、预约青边、旧记录灰边及各自角标。

### 🔴 致命弱点

取消请求不能证明服务离线；不能通过隐藏所有错误来消除误报。仅取消分支保留旧状态，真实失败仍展示。

### 🟡 主要缺陷

独立刷新若和主同步并发，会竞争快照与限频；全部角标用热度色，会把预约、评分或旧记录误读为热门。

### 🟢 改进建议

刷新互斥、共享限频且复用原数据流程；光边加粗同时保留颜色和文字类别双重区分。

### 📋 审查总结

维持既有榜单口径与身份规则，修复取消语义、缩短重试入口并加强可辨识性。

## 站内热门榜联动（2026-10-29）

电影／剧集共用卡片与详情接入已有站内三榜：橙红边表示站内热门、金边表示外部热榜、金白双层边表示「多榜共热」。展开标识可见三榜各自名次、快照时间及外部来源。共热卡出现／悬停时单次扫光，减少动态效果和后台守卫继续生效。

### 🔴 致命弱点

近日／本周／本月并非独立来源；同日多次同步也不能证明跨日持续。不能靠三榜数量或同步次数制造「多榜共热」「持续上榜」。

### 🟡 主要缺陷

漏采日期、历史碎片、同日中途离榜再入榜、旧榜未更新都可能制造虚假的持续性。站内名次不能直接与外部名次相加。

### 🟢 改进建议

站内各 scope 独立计算，当前有效期 48 小时，与真正的近期外部热度同时存在才共热。历史回看北京时间最多 14 个自然日，所有已观察快照均有该作品才累计，相邻日期必须连续；缺席、缺日、批次条数不足当前 85% 即中断。同一天只计一次。界面解释观测范围及未采样限制。

### 📋 审查总结

仅读当前三榜及有限历史，新增缓存只有当前榜单成员；不修改榜单写入和身份、不新建数据库表、不新增请求或定时器。测试覆盖三榜独立排名、移出最新榜、北京时间跨日、同日去重、断日／中途离榜／历史碎片与共热的过期及类别排除。
