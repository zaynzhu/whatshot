## getVideoMovieList：筛选与排序参数（2026-09-12 实测）

来源：逆向原站前端 `tvseries-004f635a.js`（剧集页）与 `movie-c68dea68.js`（电影页），与 WhatShot 现用 `ButaiClient.fetchMovieList` 的构造方式一致。原站把这些参数序列化进 URL 路径（`/tvseries/0_0_2026_0_0_1_1_0_0x10_0_0_0.html` 形式），app 端直接作为 query 传即可。

全部参数（空串或 `"0"` = 不筛选；默认 `sg=1`）：

| 参数 | 含义 | 取值（实测通过） | 实测样例 |
|------|------|------------------|----------|
| `sa` | 分类 | `1` 电影 / `2` 剧集 | 必传 |
| `page` | 页码 | 数字，每页 25 条 | — |
| `sg` | **排序** | `1` 更新时间（资源更新，站方默认）/ `3` 添加时间 / `4` 上映时间（niandai 降序）/ `5` 评分最高 / `6` 评分人数 | `sg=4` 首页出现 2030 年未播条目（垃圾数据顶前排）⚠️ |
| `sc` | 类型（多选） | 类型字典 title，逗号分隔，原站多选时前缀 `dx,`；`dx` 单独传=多选模式 | 未单独实测多选语法 |
| `sd` | 地区 | 地区字典 title | `sd=美国&se=2026` → total 1540 ✅ |
| `se` | **年代** | 年代字典 title：`近三年`/`2026`…`2017`/`20年代`/`10年代`/`00年代`/`90年代`/`80年代`/`更早` | `se=2026` → total 8060；`se=90年代` → total 502（返回 1994-1999 条目）；`se=近三年` 同 `se=2026`（疑似等值实现）⚠️ |
| `sf` | 画质 | 画质字典 title | 未实测（参数已确认存在） |
| `sh` | 标签 | 标签字典 title | 未实测（参数已确认存在） |
| `status` | 更新状态 | `更新中` / `已完结` | `status=更新中` → total 2366 ✅ |
| `pfrs` | 评分下限（原站为滑杆） | 数字 | 未实测 |
| `pfqj` | 评分区间（原站为滑杆） | `"低x高"` 如 `0x10` | 未实测 |
| `imdb` | 仅看有 IMDb | `0`/`1` | 未实测 |
| `iswp` | 仅看有网盘 | `0`/`1` | 未实测 |

返回字段与 requirements.md 已记录的一致（`niandai` 年代、`ejs`、`ecc` 等），本文不重复。`total` 字段为该筛选下命中总数。

## getVideoTypeList：筛选字典（2026-09-12 实测全结构）

无业务参数，返回 `data.t1`~`t5` 五个数组，每项 `{id, idcode, type, title, thesaurus, rules, relationship, weight, ...}`：

| 键 | 维度 | 取值（title） | 条数 |
|----|------|---------------|------|
| `t1` | 类型 | 喜剧/剧情/动作/爱情/科幻/动画/悬疑/惊悚/恐怖/犯罪/同性/音乐/歌舞/传记/历史/战争/西部/奇幻/冒险/灾难/武侠/真人秀/纪录片 | 23 |
| `t2` | 地区 | 大陆/欧美/美国/香港/台湾/日本/韩国/英国/法国/德国/西班牙/印度/泰国/俄罗斯/加拿大/澳大利亚/瑞典/巴西 | 18 |
| `t3` | 年代 | **近三年/2026/2025/…/2017/20年代/10年代/00年代/90年代/80年代/更早**（`近三年` 的 thesaurus 为 `近三年@2023-2026`，是预置动态区间） | 17 |
| `t4` | 画质 | HDTV/WEB-1080P/WEB-4K/1080P蓝光/1080P-Remux/4K蓝光/4K-Remux/3D/杜比视界/蓝光原盘/4K蓝光原盘/枪版 | 12 |
| `t5` | 标签 | 心理/冷门/人性/丧尸/搞笑/吸血鬼/温情/魔幻 | 8 |

注意：字典 `title` 就是筛选参数的取值（原站直接用中文 title 做 `sc/sd/se` 的值）。

## getVideoDetail：`release` 字段覆盖率（2026-09-12 抽样实测）

详情接口用 `id` 参数，但**传豆瓣 ID 才是正确用法**（原站详情页路由 `/mv/<doub_id>`；传内部 ID 报 `影视资料不存在或已被删除`，WhatShot 现行实现即传 `douban_id`）。

`release`（详情页渲染为"上映日期/首播"）的覆盖规律，抽样结果：

| 样例 | 类型 | release 返回 |
|------|------|--------------|
| 老友记 第八季（doub 3286548） | 完结老剧 | `2001-09-27(美国)` ✅ |
| 火线交锋（doub 1420031） | 老电影 | `2004-05-25` ✅ |
| 假面骑士ZEZTZ（doub 37284436，更新至47集） | 播出中动漫 | 空 ⚠️ |
| 冬城猎凶（doub 37264799，更新至8集） | 播出中新剧 | 空 ⚠️ |
| 重案六组：消失的警号（doub 38407616） | 播出中 | 空 ⚠️ |
| 生逢其时 / 猎罪现场（doub 37233336 / 37855452） | 播出中 | 空 ⚠️ |

**结论：`release` 只在老条目上有值，正在播出/近期新条目上基本为空**（与本地库一致：125 部播出中剧集 `release_info` 覆盖 0，只有 61 条老条目有值）。所以它**不能**作为"播出时间轴"的数据源；它也只在详情接口返回，列表接口没有。

顺带实测：详情接口 `created_at` 是条目首次录入站点的时间（老友记 2025-05-01、火线交锋 2022-10-19），`updated_at`≈`seed_updated_at`。

## 播出日期可得性结论（2026-09-12，多源验证）

但 ai0 全部接口（列表 + 详情）**没有逐日播出数据**；`release` 只有首播日且新剧为空。验证过的外部路径：

- **豆瓣 rexxar 接口**（`m.douban.com/rexxar/api/v2/tv/<douban_id>`，移动端 UA + Referer `m.douban.com/tv`，无需登录）：**有 `pubdate`**，如《飞到我心上》返回 `['2026-08-31(中国大陆)']`，与豆瓣网页一致。但豆瓣 kind 路径必须分对：老友记条目在豆瓣属电影页 subject（`/movie/2641586`），剧集用 `/tv/`； WhatsNew 的 `doubanAdapter.ts` 已有同款接口的成熟用法可参考。后续扩展验证（国产在播 11 部样本 100% 可得、years 错标实例、分集接口 404）见 [douban-premiere-date-assessment.md](douban-premiere-date-assessment.md)。**已批准接入：一期单源例外，仅限用已有 douban_id 补首播日**，边界与节奏见 [requirements.md](requirements.md) 列表筛选与首播时间线一节
- **豆瓣逐集接口**（`rexxar/api/v2/tv/<id>/episodes`）：实测 HTTP 404（traversal_error），**不可用**；网页版分集页（`subject/<id>/episode/N`）存在但样本内"播放时间"为"暂无"且无 Cookie 访问会进 sec.douban.com 安全页——逐集日程路线已按用户澄清放弃（目标是首播日，不是逐集日）
- **tvMaze**（WhatsNew 的播出表来源）：用本库播出中剧集的 IMDb ID 实测三部全部未收录；CN 播出表仅 30 条且多为动画——中文剧覆盖≈0，不可用
- ~~由此推出可用的替代口径：本地 observations 表推导"集数更新观察日"~~（**已废弃**：2026-09-13 用户澄清目标为首播日排序，观察日方案退役，仅保留在 [whatsnew-reuse-assessment.md](whatsnew-reuse-assessment.md) §4.2 作为历史评估）
